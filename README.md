# Open Source Project - Philosopher-API
if you have knowledge about philosophy and you analyze about society etc, you can contribute to this project.

## 💓 How to Contribute?
you can clone this project, add new branch on your local, go to file /json/philosopher.json or /json/niche.json, add your philosophy or analyze about stuff and you can push it.

## ⚡️ Quick Start

base url: `https://philosopher-api.vercel.app`

**getAllPopularPhilosophers()**<br>
`/philosopher/popular/all`

**getDetailPopularPhilosopher(id)**<br>
`/philosopher/popular/${id}`

**getAllNichePhilosophers()**<br>
`/philosopher/niche/all`

**getDetailNichePhilosopher(id)**<br>
`/philosopher/niche/${id}`
